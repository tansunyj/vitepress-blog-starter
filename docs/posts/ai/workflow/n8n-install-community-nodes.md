前面我的一些文章读取数据然后是存放到google sheets在线文档中，那如果有部分朋友实在没有gmail账号，那该把一些数据存放到哪呢？

当然最好的选择是飞书了！

那现在又遇到另外一个问题，好像n8n官方节点库没有飞书节点啊！

那怎么办呢？我们一起来看看

**0\*\*\*\*1****插&#x4EF6;****0****&#x31;\*\*\*\*验证**

你看我现在在工作流工作台中搜索，如：

![图片](/images/ai/workflow/article-1770690620339/2.jpg)

按feishu搜索没有任何结果

那是不是没办法了呢？NO!看我带你来找feishu插件！

**&#x30;****2****&#x6E;8n中找**

想要安装插件最正宗当然还是从设置中找了，你需要按照如下步骤操作：

（点击左下角的settings，然后选择Community nodes菜单）

![图片](/images/ai/workflow/article-1770690620339/3.jpg)

点击这个红色的按钮

![图片](/images/ai/workflow/article-1770690620339/4.jpg)

点击browse按钮，进入到<https://www.npmjs.com网站/：>

![图片](/images/ai/workflow/article-1770690620339/5.jpg)

然后在这个网站中搜索feishu关键词，看看搜索结果和插件readme介绍，如：

![图片](/images/ai/workflow/article-1770690620339/6.jpg)

我们输入n8n-nodes-feishu-lite然后继续搜索

![图片](/images/ai/workflow/article-1770690620339/7.jpg)

底下有该插件的详细介绍之类的，请自行阅读！

好了，既然找到了，那就剩安装了！

安装：我推荐在n8n中安装，这样对我们最友好，操作最简单，如：

![图片](/images/ai/workflow/article-1770690620339/8.jpg)

输入插件名称，然后点击install按钮，安装完毕后这里就有这个插件了！

![图片](/images/ai/workflow/article-1770690620339/9.jpg)

接着，我们回到工作流工作台，搜索feishu，看看结果：

![图片](/images/ai/workflow/article-1770690620339/10.jpg)

![图片](/images/ai/workflow/article-1770690620339/11.jpg)

嗯，基本都有了！

**&#x30;****3****&#x5176;他插件**

例如，后续我需要开发微信公众号工作流，那么我需要搜索n8n-nodes-wechat，然后可以找到：

![图片](/images/ai/workflow/article-1770690620339/12.jpg)

如果需要小红书插件，那么可以搜索n8n-nodes-xhs等等

![图片](/images/ai/workflow/article-1770690620339/13.jpg)

安装过程同理！这里就不再废话了！

**02****写在最后**

好了，既然现在我们已经把需要的节点安装好了，后续我们将去飞书创建appId、appSecret然后实现在线excel文档的读写操作！
