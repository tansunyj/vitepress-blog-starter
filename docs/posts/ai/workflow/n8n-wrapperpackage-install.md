我这些天学习n8n也遇到一个问题，那就是本地windows电脑的docker动不动就崩了（其实是windows外挂得ubuntu老是出故障）！

没法正常使用n8n那这个就很难受！好在官方文档中说n8n可以以npm的方式来安装，虽然这不是官方最推荐的做法，但是也能救救急！

所以我就好好得把npm安装方式记录下来了！

**0\*\*\*\*1****nodejs安装**

想要使用npm安装，需要先安装nodejs，详细步骤如下：

**&#x30;****1****&#x5B89;装nodejs**

官网：<https://nodejs.org/en>

![图片](/images/ai/workflow/article-1770690615579/2.jpg)

点击这里的下载按钮，然后选择自己平台的安装包，如（我是windows电脑）：

![图片](/images/ai/workflow/article-1770690615579/3.jpg)

上面记住一定要选择版本号带LTS的，这是稳定版本，一般支持的会好一些，不要选太新或太旧的版本。n8n官网有列举匹配的nodejs版本号范围，如：

![图片](/images/ai/workflow/article-1770690615579/4.jpg)**&#x30;****2****&#x5B89;装**

下载到安装包后下一步下一步安装！

安装完毕后在命令行窗口中输入命令，如：

```
E:\docker\.n8n>node -v
```

如果说在命令行中执行上面的命令能够打印出正确的版本号，那么你就具备了安装n8n的前置条件；

**0\*\*\*\*2****安装n8n**

这里安装n8n可就比使用docker简单太多了，步骤如下：

**&#x30;****1****&#x5B89;装**

打开命令行窗口，执行命令，它会安装最新稳定版本：

```
npm install n8n -g
```

等命令执行完毕，就完事了！这个是全局安装，当前机器所有项目、用户均可使用！

或者使用如下命令，指定安装的版本号，如：

```
npm install -g n8n@2.1.4
```

当前npmjs.org上最新稳定版本是2.1.4，我们就可以安装这个

![图片](/images/ai/workflow/article-1770690615579/5.jpg)**&#x30;****2****&#x914D;置**

安装好之后我们就可以正常使用n8n了，不过我觉得需要先配置2个环境变量，配置好之后，不管是后续你继续使用npm方式启动n8n或者docker方式启动n8n，都不会丢失任何数据。

下面可以看看我本地的配置：

```
## 用户目录
```

如图：

![图片](/images/ai/workflow/article-1770690615579/6.jpg)

这里，我说说为什么要把N8N\_USER\_FOLDER配置到E盘呢（你自己想放D、F、G都行，无所谓）？

n8n默认安装时用户目录在C:\Users\Administrator\\.n8n。。这里的一个比较危险的问题是：我们的电脑可能会中毒、崩溃、磁盘爆满等各种意外导致C盘可能出问题，所以一般把这些东西放其他盘！

![图片](/images/ai/workflow/article-1770690615579/7.jpg)

注：这里config文件、database.sqlite文件是n8n最重要的2个文件。

**&#x30;****3****&#x542F;动**

这种方式安装n8n简单，启动也是简单，直接在命令行中执行，如：n8n start

![图片](/images/ai/workflow/article-1770690615579/8.jpg)

就可以正常的访问啦！

![图片](/images/ai/workflow/article-1770690615579/9.jpg)**0\*\*\*\*3****小经验分&#x4EAB;****0****&#x31;\*\*\*\*数据文件目录**

这种使用npm安装n8n后，工作流中读取本地文件时就和docker不一样了（docker还需要挂载外部文件），这里直接把数据文件放E:\docker\n8n\_data文件夹底下，然后使用绝对路径就好了，如：

![图片](/images/ai/workflow/article-1770690615579/10.jpg)

![图片](/images/ai/workflow/article-1770690615579/11.jpg)

这样，我们在工作流中就可以正常使用到数据文件了！
