今天看到reddit上有一个国外的动手达人把openclaw安装到了手机上，可以在手机上运行openclaw，这个真是打开了一个新的大门。

确实我们每个家庭基本上都会有一些淘汰的手机，现在手机的配置跑这个openclaw绰绰有余！

帖子原文：

<https://www.reddit.com/r/AgentsOfAI/comments/1qybhk2/this\\_guy\\_installed\\_openclaw\\_on\\_a\\_25\\_phone\\_and/>

![图片](/images/ai/agent/article-1770690721183/2.jpg)

当前这个安装仅限于安卓手机，因为安卓本来就是基于linux开发，所以安装openclaw也没太大问题。

视频中该博主在discord中给openclaw发送命令，手机上的手电筒可以顺利打开，如：

![图片](/images/ai/agent/article-1770690721183/3.jpg)

然后过了几秒钟，openclaw关闭它！整个过程非常丝滑。

这个博主的视频意义在于openclaw确实是可以部署在自己淘汰的这些旧手机，如果说旧手机配置过关，那废旧物再次利用确实也是可以的。

那这样的话，我们很多人可以自行部署openclaw，然后也不需要购买服务器，配置好之后，同样能够取得完全一样的效果！

在X上看到有人对这个视频进行评论，如果说收购一堆旧手机都安装上openclaw，那这个想象空间会非常大！
