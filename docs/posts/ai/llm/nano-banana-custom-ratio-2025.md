## 二、生图

下面，我将详细介绍如何来生成各种不同尺寸的图片

## 1.生成1:1尺寸图

提示词：

```
花果山水帘洞前有一个瀑布，瀑布旁边有一个很大的广场，孙悟空带领着一群猴子在训练
```

这个nano banana默认就是生成的1:1尺寸的图片，接下来我需要使用一些方法来让nano banana生成不同尺寸的图片。
准备工作：需要准备16:9  9:16  3:4  4:3这4种尺寸的白底图片

## 2.生成16:9图片这里在aistudio种使用16:9白底图片，再使用与上面类似的提示词，不过需要略微做一下修改

```
以附件白底图片作为画布绘制如下的场景（需填充满该白底图片，图片不要在左边、右边留空白）：花果山水帘洞前有一个瀑布，瀑布旁边有一个很大的广场，孙悟空带领着一群猴子在训练
```

![图片](/images/ai/llm/6.jpg)


这里显示得就是16:9宽屏得图片。
