## 介绍

### 一、简介

##### 简介：

1.obsidian web clipper是一款免费开源的浏览器插件，它的主要功能是帮助用户将网页内容保存到obsidian笔记中，不过它也支持将文档保存为markdown格式文档。

2.该插件支持chrome浏览器、firefox浏览器、safari浏览器，以满足不同浏览器用户需求。

3.它可以通过自定义指令处理任何类型网页，入总结、翻译、提取、格式转换等；

项目地址：<https://github.com/obsidianmd/obsidian-clipper>

下载地址：<https://pan.quark.cn/s/80f6b60d904d>

注：带chrome的是chrome插件，带safari的是safari插件，其他类似！

### 二、功能

网页剪辑：快速保存页面内容到obsidian笔记中；

高亮功能：在网页上高亮重要功能，并保存到笔记；

自定义模板：创建和使用自定义模板，优化内容保存格式；

变量和过滤器：使用变量和过滤器，预填充和修改模板内容；

隐私保护：不收集用户数据，代码开源；

多浏览器支持：支持chrome、firefox、safari浏览器；
